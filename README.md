# SMS.RU: баланс и отправки

Мини-дашборд: баланс аккаунта sms.ru, предупреждение при балансе ниже 5000 руб., количество SMS и сумма за сегодня, за все время и по каждому дню с первой записи.

## Настройка

1. Скопируйте `.env.example` в `.env` и вставьте ключ API из личного кабинета sms.ru (раздел «API»):

   ```bash
   cp .env.example .env
   ```

2. Проверьте обновление данных:

   ```bash
   python3 sms_dashboard.py update
   ```

3. Запустите страницу:

   ```bash
   python3 sms_dashboard.py serve
   ```

   Откройте http://127.0.0.1:8765. Пока сервер работает, данные обновляются автоматически раз в сутки. Кнопка «Обновить данные» запрашивает их вручную.

## Как считается статистика

sms.ru не отдает через API общую статистику отправок за день. Поэтому количество и сумма считаются по sms_id, которые вы записываете при каждой отправке:

```bash
python3 sms_dashboard.py record 000000-000001 000000-000002
```

ID возвращает метод `sms/send` в поле `sms`. Стоимость каждого сообщения при обновлении берется из метода `sms/status`.

Баланс, который показывает страница, берется из `my/balance` и обновляется каждый день.

## Ежедневное обновление без открытой страницы (cron)

Откройте `crontab -e` и добавьте строку (путь замените на свой):

```
0 9 * * * cd "/путь/к/sms-dashboard" && /usr/bin/python3 sms_dashboard.py update >> data/update.log 2>&1
```

## Файлы

- `sms_dashboard.py` — обновление данных (`update`), запись sms_id (`record`), веб-сервер (`serve`)
- `index.html` — страница дашборда
- `data/dashboard.json` — последние данные для страницы
- `data/sent_ids.json` — записанные sms_id и их стоимость
- `.env` — ключ API (не коммитить в git)
